# Sound recordings

Real recordings from Wikimedia Commons and OpenGameArt. Commons files are used unmodified (the game picks loop regions and changes playback speed and volume at run time); files marked as trimmed were cut and resampled by tools/prepare_shot.mjs.

- **Inline piston engines (Rolls-Royce Merlin running)** — [RR Merlin 66-266.ogg](https://commons.wikimedia.org/wiki/File%3ARR_Merlin_66-266.ogg) by Peter Ellis, CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0)
- **Radial and rotary piston engines (crop-duster radial)** — [Stanton Special Cropduster (1953).ogg](https://commons.wikimedia.org/wiki/File%3AStanton_Special_Cropduster_(1953).ogg) by Edvvc, CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0)
- **Piston aircraft fly-bys (Spitfire)** — [Spitfire fly past at RAF Halton.ogg](https://commons.wikimedia.org/wiki/File%3ASpitfire_fly_past_at_RAF_Halton.ogg) by LouiseBrown1981, CC BY-SA 3.0 (https://creativecommons.org/licenses/by-sa/3.0)
- **Jet engines, afterburner and jet fly-bys (Saab J 35 Draken)** — [WWS SaabJ35DDraken8211passingtwotimes.ogg](https://commons.wikimedia.org/wiki/File%3AWWS_SaabJ35DDraken8211passingtwotimes.ogg) by Work With Sounds / Torsten Nilsson, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0)
- **Explosions** — [Explosion 10.ogg](https://commons.wikimedia.org/wiki/File%3AExplosion_10.ogg) by tcpp, Public domain
- **Explosions** — [Explosion-LS100155.ogg](https://commons.wikimedia.org/wiki/File%3AExplosion-LS100155.ogg) by Fg2, Public domain
- **Large explosions and bomb impacts** — [Explosions-LS100150.ogg](https://commons.wikimedia.org/wiki/File%3AExplosions-LS100150.ogg) by Fg2, Public domain
- **Rifle-calibre machine guns (.30-06 Springfield M1917, near)** — [B_24P.wav](https://opengameart.org/content/the-free-firearm-sound-library) by The Free Firearm Sound Library (Still North Media), via OpenGameArt, CC0
- **Distant gunfire (.30-06, mid distance)** — [B_16P.wav](https://opengameart.org/content/the-free-firearm-sound-library) by The Free Firearm Sound Library (Still North Media), via OpenGameArt, CC0
- **7.62x54R machine guns (Mosin-Nagant, near)** — [M_21P.wav](https://opengameart.org/content/the-free-firearm-sound-library) by The Free Firearm Sound Library (Still North Media), via OpenGameArt, CC0
- **Japanese rifle-calibre guns (Arisaka)** — [E_18P.wav](https://opengameart.org/content/the-free-firearm-sound-library) by The Free Firearm Sound Library (Still North Media), via OpenGameArt, CC0
- **Propeller aircraft cruise (cockpit engine loop)** — [Propeller-plane-flying-steady-01.wav](https://commons.wikimedia.org/wiki/File:Propeller-plane-flying-steady-01.wav) by Versatile Virtuoso, CC BY-SA 4.0 — trimmed to 6 s, mono, 22 kHz
